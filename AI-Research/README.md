# My Travel Buddy — AI API Research and Starter Code

This package contains OpenAI API setup documentation, travel-requirement research, an MVP architecture decision, CommonJS Express starter code, and integration tests using curl.

Copy the documentation into `docs/08-AI-INTEGRATION/` and review the Server code with the team before merging.

The OpenAI code is ready after installing dependencies and adding a valid API key. The travel-requirements route intentionally returns official verification links rather than claiming live personalized entry clearance.
